# Glossário e terminologia

| Preferir | Evitar ou qualificar |
|---|---|
| plataforma modular | smartwatch como contribuição isolada |
| módulo autocontido | “plugin” sem definição |
| contrato uniforme | API genérica sem descrição |
| inicialização não fatal | “à prova de falhas” |
| continuidade das funções independentes quando um sensor estiver ausente ou apresentar falha | funcionamento degradado |
| tolerância a falhas | confiabilidade absoluta |
| teste funcional | validação, quando não houve método |
| estimativa de SpO₂ | medição clínica |
| comparação informal | precisão, sem referência |
| folha de dados | datasheet em texto corrido |
| barramento compartilhado | rede I²C |
| recuperação pós-NACK | correção automática genérica |
| *clock stretching* | sincronização de relógio |
| clock, para sinal, fonte ou frequência de temporização | relógio, nesse contexto |
| interface gráfica | GUI, salvo primeira definição |
| frequência cardíaca | batimento cardíaco como grandeza |
| iluminância | luminosidade, quando a grandeza é lux |
| índice UV | radiação UV, quando se trata da escala |

## Siglas

- ADC — conversor analógico-digital
- DMA — acesso direto à memória
- EMA — média móvel exponencial
- FC — frequência cardíaca
- I²C — Inter-Integrated Circuit
- NVS — Non-Volatile Storage
- PPG — fotopletismografia
- RTC — relógio em tempo real
- RTOS — sistema operacional de tempo real
- SPI — Serial Peripheral Interface
- UVI — índice ultravioleta
